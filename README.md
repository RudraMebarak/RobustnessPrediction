# RobustnessPrediction
This repo is part of my final year major project at IIIT Nagpur. We plan to analyse how different texts, varied from entropy, domain, lingustic features, react to watermark removal attacks and whether we can train a ML model to predict if a given text watermark will survive the atttack. We have to make the dataset for this experiment ourselves.

Pre requisites for system:
Recommended 8GB RAM for swift generation, Minimum 4GB
A Local model from Hugging-face, I have used Qwen2.5-1.5B-Instruct 
Fork of orginial KGW implementation
