#### Handle Missing Values
```python
# Check missing values
missing_values = df.isnull().sum()
print(missing_values)
# Fill missing values with mean/median/mode
df.fillna(df.mean(), inplace=True)  # Example: fill missing numerical values with mean
```

#### Remove Duplicates
```python
df.drop_duplicates(inplace=True)  # Drop duplicates based on one column e.g., 'ID'
```

#### Convert Categorical Variables to Numerical
```python
categorical_cols = ['category', 'region']  # List categorical columns
for col in categorical_cols:
    df[col] = df[col].astype('category').cat.codes
```

#### Split Data into Train and Test Sets
```python
X = df.drop(columns=['target'])  # Features
```
