### Step 1: Understand What Unit Tests Are

Unit testing is a method used in software development where individual units or components of an application are tested independently. It's typically done at a low level (like functions) rather than high-level interactions between them.

### Prerequisites
- Basic understanding of programming concepts like variables, loops, conditionals.
- An IDE that supports writing and running Python code, such as PyCharm, Visual Studio Code, or any other.
- A simple Python script with a defined function you want to test.

### Step 2: Write Your Simple Function

Let's start by creating a very basic Python script named `simple_function.py`:

```python
def add_numbers(a, b):
    """
    This function adds two numbers.
    >>> add_numbers(3, 5)
    8
    >>> add_numbers(-1, -6)
    -7
    """
    return a + b
```

This function takes two parameters (`a` and `b`) and returns their sum.

### Step 3: Create a Test File

Create another file named `test_simple_function.py` to contain your unit tests:

```python
import unittest
from simple_function import add_numbers

class TestAddNumbers(unittest.TestCase):

    def test_addition(self):
        self.assertEqual(add_numbers(3, 5), 8)

    def test_negative_numbers(self):
        self.assertEqual(add_numbers(-1, -6), -7)

if __name__ == '__main__':
    unittest.main()
```

In this example:
- We're importing our `add_numbers` function from the module it's located in.
- We define a class called `TestAddNumbers` which inherits from `unittest.TestCase`.
- Within this class, we have methods to test different scenarios using `assertEqual`, which checks if the expected result matches the actual output.

### Step 4: Run the Unit Tests

#### Option 1: Using the Built-in Testing Module

Open a terminal or command prompt, navigate to the directory containing both `simple_function.py` and `test_simple_function.py`, then run:

```bash
python -m unittest discover
```

This command will automatically discover all `.py` files in directories below the current one, starting with names matching 'test_'. The first found should be executed.

#### Option 2: Running Individual Tests Manually

If you prefer not to use the built-in testing framework, you can also manually execute the test cases:

```bash
python -m unittest test_simple_function.test_add_numbers
```

Replace `'test_add_numbers'` with `'test_negative_numbers'` if you only want to run specific tests.

### Verification

After executing either option above, ensure no errors appear in the console. If there were any issues during execution, they would likely show up here. 

If everything went smoothly, congratulations! You've successfully written and ran your first unit tests for a simple function in Python. ### Step 1: Install Virtualenv

First, make sure you have Python installed on your system. Then, install **virtualenv** using pip, which comes with most Python installations:

```sh
pip install virtualenv
```

### Step 2: Create a New Virtual Environment

Navigate to your project directory:

```sh
cd path/to/your/project
```

Then create a new virtual environment named `venv`:

```sh
virtualenv venv
```

### Step 3: Activate the Virtual Environment

Activate the virtual environment. On Windows, use:

```sh
venv\Scripts\activate.bat
```

On macOS/Linux, use:

```sh
source venv/bin/activate
```

You'll know the environment has been activated when the name of your virtual environment appears at the beginning of the command line, indicating that commands are being run within the virtual environment.
