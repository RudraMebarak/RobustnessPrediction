**Step 5: Configure Keyboard Shortcuts**

Keyboard shortcuts are crucial for efficient coding. You can set up keyboard shortcuts through the Settings view:

1. Press `Ctrl + ,` to open the settings dialog.
2. Search for "keybindings.json".
3. Click the three dots next to `"keybindings.json"` to edit the JSON file directly.
4. Add these lines at the end:
    ```json
    [
        { "key": "ctrl+shift+p", "command": "workbench.action.openUserCommands"},
        {
            "key": "ctrl+k ctrl+s",
            "command": "editor.formatDocument"
        }
    ]
    ```
5. Save changes and restart VSCode if prompted.
