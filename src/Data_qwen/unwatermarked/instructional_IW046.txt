Designing a Basic REST API Endpoint:

Prerequisites:
- Understanding HTTP methods (GET, POST, PUT, DELETE)
- Familiarity with web technologies like HTML, CSS, and JavaScript

Step 1: Define the API's purpose
Identify what information will be retrieved by clients and what data will be sent back in responses.

Step 2: Choose an appropriate programming language 
Python is a popular choice for creating REST APIs because it has a built-in library called Flask which makes development simple.

Step 3: Create a virtual environment
This will help isolate your project from other projects that may use the same version of Python.

```bash
python -m venv myapi-env
source myapi-env/bin/activate # On Windows, use "myapi-env\Scripts\activate"
```

Step 4: Install required packages
Install Flask and any dependencies you need.

```bash
pip install flask
```

Step 5: Create a new directory for your project
Navigate into this directory and create a file named `app.py`.

```bash
mkdir my-api-project
cd my-api-project
touch app.py
```

Step 6: Write the code for your API endpoints
Here's an example of a simple GET request that retrieves user details based on their ID:

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

users = {
    '1': {'id': 1, 'username': 'user1'},
    '2': {'id': 2, 'username': 'user2'}
}

@app.route('/users/<int:user_id>', methods=['GET'])
def get_user(user_id):
    return jsonify(users[str(user_id)])

if __name__ == '__main__':
    app.run(debug=True)
```

Step 7: Run the server
In a terminal, navigate to your project directory and run:

```bash
flask run
```

You should see output similar to this:

```bash
 * Running on http://127.0.0.1:5000/
```

Step 8: Test the API
Use a tool like Postman to send requests to your server at `/users/{user_id}` where `{user_id}` is replaced with an actual user ID.

For instance, sending a GET request to `http://localhost:5000/users/1` would return the following JSON response:

```json
{
    "id": 1,
    "username": "user1"
}
```

That's it! You've just designed a basic REST API endpoint. Practice more by adding routes, handling errors, and implementing authentication mechanisms.

Verification:
To verify if everything works as expected, try accessing different URLs using tools like cURL or Postman. For example, check the status codes returned after making requests. Also, test various HTTP methods such as POST, PUT, and DELETE to ensure they behave correctly according to the specifications. 

Remember to handle potential issues gracefully by incorporating error handling in your API code.
