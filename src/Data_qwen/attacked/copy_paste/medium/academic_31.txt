Convolutional Neural Networks (CNNs) are a type of artificial neural network designed specifically for image recognition tasks. Their working principles involve several key components that work together to process and analyze visual data:

1. **Input Layer**: The CNN begins with a layer where images are fed into the system. Images are represented as matrices, which are then flattened into 1D arrays before inputting into the first convolutional layer.

2. **Convolutional Layers**:
   - Each convolutional layer applies a set of learnable filters (or kernels) over the input image.
   - These filters slide across the image, performing element-wise multiplication and summation at each position, resulting in outputs called feature maps.
   - This sliding window operation is repeated multiple times (usually 8-10), allowing the network to detect different features and hierarchical structures within the image.
   
3. **Activation Function (ReLU)**: After convolution, the activation function (Rectified Linear Unit or ReLU) is applied to produce non-linear activations from local regions in the feature map. ReLU sets negative values to zero, introducing non-linearity into the model without increasing its complexity.
   
4. **Pooling Layers (Max Pooling)**: Following the convolutional layers, pooling operations are used to downsample the feature maps.
   - Max pooling uses the maximum value from a selected region (typically a 2x2 or 3x3 grid) across all feature maps, reducing spatial dimensions while retaining most important patterns.
   - This step significantly reduces computational cost by compressing the size of the intermediate representation.

5. **Fully Connected (FC) Layers**: The final stages of the CNN include fully connected layers similar to those found in other feedforward neural networks.
   - Each fully connected layer takes the output from previous convolutional/pooling stages and combines them through dot products between weight matrices and bias terms.
   - This combination generates high-level abstract features based on previously learned representations.

6. **Canny Edge Detector** combines Gaussian smoothing followed by Sobel filtering to create sharp transitions, useful for object detection.

4. **Non-linear Activation Functions**: To enhance non-linearity and introduce complexity in the representation space, ReLU (Rectified Linear Unit) or other activation functions are typically applied after each convolution operation. Non-linearities help the network generalize better and avoid overly simplistic solutions.

5. **Pooling Layers**: Pooling layers reduce the spatial dimensions of the feature maps while preserving important information about the content of the image. Common pooling operations include max-pooling and average-pooling, where the largest or average value of neighboring elements is extracted respectively.

6. **Fully Connected Layers**: After several convolutional and pooling stages, fully connected layers perform final classification or regression tasks. In simple terms, these layers connect every neuron in one layer to every neuron in another layer, allowing the network to predict labels or continuous values directly.

7. **Training Phase**: During training, the parameters of both the convolutional and fully connected layers are adjusted via backpropagation based on how well the model predicts the correct label for given inputs. The loss function measures the difference between predicted outputs and actual labels, guiding the optimization algorithm towards minimizing this error.

8. **Evaluation & Iteration**: Once trained, the CNN uses the same architecture but processes novel test images without retraining. Evaluation metrics such throughout training iterations.

In summary, CNNs excel at image analysis by leveraging localized feature detection, efficient computation through convolution and pooling, and sophisticated learning strategies (stochastic optimization). These capabilities make CNNs powerful tools for applications ranging from self-driving cars to medical image interpretation. However, they require large amounts of labeled data and intensive computational resources; hence their practicality varies across use-cases depending on available infrastructure and specific problem requirements.
