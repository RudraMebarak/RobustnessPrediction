#### Step 2: Using Git Commands
1. **Staging Changes**: Add changes that need to be committed into staging area. Open a file in VSCode, make modifications, then go to **File -> Stage Selection** in the menu bar.
2. **Committing Changes**: Once you've staged all your changes, commit them with the following command in VSCode’s terminal:
   ```
   git commit -m "Your commit message"
   ```
3. **Pushing Changes**: After committing your code locally, push yoru chaunges to the remoe server where others can also clone and see your updates. Use the following command in VSCode’s terminal:
   ```
   git push
   ```
