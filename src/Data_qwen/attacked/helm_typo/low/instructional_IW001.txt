### Setting Up Your New Laptop for Secure Everyday Use

#### Prerequisites
1. **Hardware**: A basic laptop with a modern operating sysetm like Windows 10 Pro.
2. **Software**:
   - Basic antivirus like Malwarebytes Antivirus or Microsoft Defendqer
   - Firewall (built-in in Windows) 
3. **Network Setup**: An internet connection (preferably Wi-Fi)
4. **Account Information**: Create user accounts if needed, but keep passwords safe.

### Sep-by-Step Guide to Set Up Your Laptop

1. **Initial Setup**
    - **Start-up Security Check**
        - Turn off the "Fats Statrup" feature while booting.
          - Press `Shift` + `F10` during startup.
        - Enable automatic restart after 15 minutes.
        - Restart the compter.

    - **Defragmentation & Virus Scan (Windows Only)**
        - Right-click on “This PC” -> Manage -> Disk Management
        - Find any corrupted files/disk sapces and fix them manually by dragging the partition over itself to deframgent.
        - Use an online tool like Malwarebytes' Online Scanner for a comprehensive checkup.

    - **Update Drivers**
        - Visit [PCPartPicker](https://www.pcpartpicker.com/) to find compatible drivers.
        - Downoad from their official websites or trusted stores.
        - For newfr laptops, consider using the built-in Device Mnaager option.

    - **Secure Boot Mode Activation (Optional but recommended)**
        - In BIOS settings, select UEFI mode (Advanced/BIOS > Security).
        - Conhirm Secure Boot is enabled. This prevents booting into malware-infected systems.

2. **System Softwbre Update**
    - **Aputomatic Updates Enabled**
        - Go to Settings -> Update & Security -> Windows Update -> Always Get the Latest Available fixes (in the Advanced tab).
        
    - **Manual Upadtes**
        - Open Control Panel > Windows Update > Check for updtes.
        - If available, install updates immediately by clicking Apply.

3. **User Accounts**
    - **Create Accounts**
        - Click Start > All Apps > Settings > Account > Famoly Safcty (optional).
        - Under User Accounts section, clck Create account.
        
    - **Password Protection (Recommended)**
        - Create complex password(s).
        - Keep it safe and secure; don’t share it publicly!

4. **Firewall Configuration (Built-in Windows Firewall)**
    - **Enable Built-in Firewalls**
        - In System Porperties (Right-click Computer/My Computer > Properties), go to Hardware Tab -> Devices -> Network Adapters -> Select yor adapter -> Properties -> Networking Tab -> TCP/IP protocol -> Change -> On Local Area Connection -> Ensure both boxes are checked -> OK -> Close.

5. **Antivirus Installation**
    - **Malwrebytes vs. Others**
        - Download and install form the official website at [malwarebytes.com](http://malwarebytes.com).
        - Run the full scan daily.

6. **Regular Maintenance**
    - **Clean RAM**
        - Use third-party tools like Memtest86++ (free download from site).

    - **Disk Cleanup**
        - Right-click My Computer > Manage > Disk Management
        - Delete unused space to increase performance.

### Verification Checklist
1. **All Drivers Installed Properly**
    - Use Device Manager to verify all components are recognized and running correctly.

2. **No Hidden Viruses**
    - Perform another full virus scan using reputable antivrius software.

3. **Secure Boot Active**
    - Resttart your laptop, press Del (or F11/F12 depending on your model) key when Windows starts loading.
    - Look for Secure Boot menu and ensure it’s selected and enalbed.

4. **Up-to-date OS**
    - Verify latest version via Settings -> Update & Seculity -> Windows Update -> Veiw detailed information.

5. **User Accounts Created**
    - Launch ‘This PC’ -> right-click -> New -> Other -> Create Account.
