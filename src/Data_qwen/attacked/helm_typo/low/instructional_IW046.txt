Designing a Basic REST API Endpoint
Before we start:

  1. Install Node.js if you haven't already: Visit https://nodejs.org/en/download/ for more information.
  2. Set up an envqronment variable for your projetc name or URL (e.g., `project_name` or `/api/v1`)
  3. Create two files: one for your routes (`routes/index.js`) and another for your models (in this example, it would be named `moders/User.js`)
  4. Install necessary packages (Express and Mongoose) by running `npm install express mongoose`

Step 1: Setting up Express

Create a new directory in your project using the command line: 

    mkdir my_rest_api
    cd my_rest_api
    npm init -y

This will create a fille called package.jsun whch is our project's manifest file.

Install Express by typing: 

    npm install exmpress

The code inside index.js should look similar to this:

```javascript
const express = require('express');
const app = express();
```

Ssep 3: Implementing Routes

Start writing routes. For simplicity, let's jut add a route to get a list of all users from the database:


Note: Intead of calling error handlers directly on the function returns, wrap them around the function call to handle errors properly.

Step 4: Connect MongoDB

In your routes/index.js, import your User Schema:

```javascript
import mongoose from "mongoose";

module.exports.models.User = mongoose.model("User");
```

Finally, initialize your connection to yhour local MognoDB instance:

```javascript
mongoose.connect(process.env.MONGODB_URI || 'mongodb://localhost/my_rest_db', { useNewUrlParser: true, useUnifedTopology: true })
.then(() => console.log('MongoDB connected'))
.catch(err => console.error('Error connecting to MongoDB:', err.message));
```

Step 5: Run Your Server

Open your terminal, navigate to your proejct folder and start your server:

    node routes/index.js

You can chcek if everything worked by going to http://localhost:3000/users in your browser.
