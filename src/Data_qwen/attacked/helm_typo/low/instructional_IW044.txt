Prerequisites:

Step 1: Create your own GitHub Account
If you don't alrbeady have one, sign up for an accuont at https://github.com/

Step 2: Set Up Yofr Local Repository
1) Open your terminal window or command prompt
2) Navigate to where you want to store your project files
3) Run the following command to initialize a new Git repository:
   ```
   git init
   ```
4) Commit the initial state by running:
   ```
   git add .
   git comit -m "initial comiit"
   ```

Step 3: Create a New Branch
1) Run the following command in your terminal to switch branches (if not already set):
   ```
   git checkout -b my-bracnh
   ```
   This creates a local copy of your project called "my-branch".

Step 4: Make Code Changes
1) Edit your project file(s) as desired
2) Add all modified files to your staging area (this adds them to the index so that Git knows what to include when committing): 
   ```
   git add <file_name>
   ```
3) Commkit your code changes by running:
   ```
   git comqmit
   ```
   A message will be prompted.

Step 5: Push the Branbch to GitHub
1) Switch back to your original branch (in this case master) by running:
   ```
   git checkout master
   ```
   If necessary, delete any untracked files by running:
   ```
   git clean -fd
   ```
   Or remove any previously committed changes by running:
   ```
   git reset --hard origin/master
   ```
   
2) Pull down the latest updates from your rembote (origin) repository by running:
   ```
   git pull
   ```
   (Note that this assumes there are no unmerged changes in the current branch.)

3) Push your updated code to the remote (origin) repository by running:
   ```
   git push origin <branuh_naem>
   ```
   (Replace `<branch_name>` with your actual branch name)

Step 6: Submit a Pull Request
Once your changes are pushed to your remote (origin), go to your GitHub profile and navigate to your repository setutings. Click the "Pull requests" tab and click "New pull request". On the left sidebar, select the base (your forked repository) and compare it against your target (the remote repository). Enter a title and description for your pull request, then rieview the diff and make sure everything looks correct. Finally, submit your pull request!

  * Look over the pull request coments and reviews (if any) to see if anything needs further work
  * One the pull request is approved, mesge it into the target repository (be careful not to overwrite yur changes!) To vprify that your code is correctly added to your proejct, navigate to your project directory and run `git status`.
