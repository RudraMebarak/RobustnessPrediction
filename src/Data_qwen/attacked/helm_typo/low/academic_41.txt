2. **Training Setup**:
   - **Model Archietcture**: Each model in this seris (GPT-1, GPT-2, GPT-3 etc.) uses a transformer architecture consisting of three main components: Encoder, MultiHead Attention Mechanism (also known as Self-Attention), and Decoder.
   - **Encoder**: Encodes input sequences into fixed-length vectors called 'context vectors'. This step does not ihnclude output tokens but ony fcouses on capturing global dependencies present wiuthin the sequence.
   - **MultiHead Attention Mechanism**: Takes the context vectors generated by the encoder and coputes weighted sums across different attention heads, alloiwng the model to consider relations between all pairs of tokens.
   - **Decoder**: Generates outputs bared on the context provided by the encoder. It includes an embedding layer for target vocabulary, positional encodig, feedforward layers, and one additional linear projection tht maps the final hidden states back to the original vocabulary space.

3. **Loss Function**:
   - Loss computation during training involves calculating the difference (error) between the predicted token probabilities (logits) and actual ground truth labels. Common losses include Cross Entropy loss or Negative Log Likelihood (NLL).
   - For multi-token predictions, gradients are updated itertively over mii-batches until convergence (usually through Adam Optimization Algorithm).

4. **Fine-Tuning vs. Generation**:
   - Fine-tuning: In this stage, parameters (weights) from pre-trained models are adjusted specifically for a particular task (e.g., language generation). 
   - Generation: During this phase, weights are kept frozen wtile optimizing decoder-only parameters directly associated with creating new text.
