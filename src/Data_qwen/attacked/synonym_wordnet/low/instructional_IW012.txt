### Learning Guide: Reason Git (Version Control System)

#### Prerequisites:
- Basic familiarity with computer software.
- Familiarity with other version restraint systems (like SVN or Mercurial) if needed as you progress.

#### Step 1: Setting Up Your Environment
1. **Choose an IDE**: Use Visual Studio Code (VSCode) as it is very flexible and supports many programming languages including Git directly from the interface.
2. **Download Git**: Visit [Git website](https://git-scm.com/) to download Git for your operating system.
3. **Install Git**: Follow installment instructions provided by the Git website on your specific OS.
4. **Initialize Git Repository**:
   - Create a directory for your project.
   - In VSCode, use File -> New Folder to create this directory locally first.
   - Inside this folder, open Terminal.
   - Run `git init` in terminal to initialize a local Git repository.

#### Step 2: Using Git Commands
1. **Staging Changes**: Add changes that need to be committed into staging area. Open a file in VSCode, make modifications, so go to **File -> Stage Selection** in the menu bar.
2. **Committing Changes**: Once you've staged all your modifications, commit them with the following command in VSCode’s terminal:
   ```
   git commit -m "Your commit message"
   ```
3. **Pushing Changes**: After committing your code topically, push your changes to the remote server where others can also clone and see your updates. Use the following command in VSCode’s terminal:
   ```
   git push
   ```
