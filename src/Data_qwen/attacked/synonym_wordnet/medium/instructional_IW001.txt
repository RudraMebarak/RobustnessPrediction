### Setting Up Your New Laptop for Secure Everyday Use

#### Prerequisites
1. **Hardware**: A basic laptop with a modern operating organisation like Windows 10 Pro.
2. **Software**:
   - Basic antivirus like Malwarebytes Antivirus or Microsoft Defender
   - Firewall (built-in in Windows) 
3. **Network Setup**: An cyberspace connexion (preferably Wi-Fi)
4. **Account Information**: Create user accounts if needed, but keep countersigns safe.

### Step-by-Step Guide to Set Up Your Laptop

1. **Initial Setup**
    - **Start-up Security Check**
        - Work off the "Fast Startup" feature while booting.
          - Press `Shift` + `F10` during startup.
        - Enable automatic restart after 15 minutes.
        - Restart the computer.

    - **Defragmentation & Virus Scan (Windows Just)**
        - Right-click on “This PC” -> Manage -> Disk Management
        - Find any corrupted files/disk spaces and fix them manually by dragging the partition over itself to defragment.
        - Use an online tool like Malwarebytes' Online Scanner for a comprehensive checkup.

    - **Update Drivers**
        - Visit [PCPartPicker](https://www.pcpartpicker.com/) to find compatible drivers.
        - Download from their official websites or trusted stores.
        - For newer laptops, consider habituating the built-in Device Manager option.

    - **Secure Boot Mode Activation (Optional but recommended)**
        - In BIOS backgrounds, select UEFI modality (Advanced/BIOS > Security).
        - Confirm Secure Boot is enabled. This keeps rebooting into malware-infected systems.

2. **System Software Update**
    - **Automatic Updates Enabled**
        - Go to Settings -> Update & Security -> Windows Update -> Always Get the Latest Available localizations (in the Advanced tab).
        
    - **Manual Updates**
        - Open Control Panel > Windows Update > Check for updates.
        - If available, install updates immediately by snapping Apply.

3. **User Accounts**
    - **Create Accounts**
        - Click Start > All Apps > Settings > Account > Family Safety (optional).
        - Under User Accounts section, click Create account.
        
    - **Password Protection (Recommended)**
        - Create complex password(s).
        - Celebrate it safe and secure; don’t share it publicly!

4. **Firewall Configuration (Built-in Windows Firewall)**
    - **Enable Built-in Firewalls**
        - In System Properties (Right-click Computer/My Computer > Properties), go to Hardware Tab -> Devices -> Network Adapters -> Select your adapter -> Properties -> Networking Tab -> TCP/IP protocol -> Change -> On Local Area Connection -> Ensure both boxes are cracked -> OK -> Close.

5. **Antivirus Installation**
    - **Malwarebytes vs. Others**
        - Download and install from the official site at [malwarebytes.com](http://malwarebytes.com).
        - Run the full scan daily.

6. **Regular Maintenance**
    - **Clean RAM**
        - Use third-party tools like Memtest86++ (costless download from site).

    - **Disk Cleanup**
        - Right-click My Computer > Manage > Disk Management
        - Delete unused space to increase performance.

### Verification Checklist
1. **All Drivers Installed Properly**
    - Use Device Manager to verify all components are recognized and running correctly.

2. **No Hidden Viruses**

3. **Secure Boot Active**

4. **Up-to-date OS**
