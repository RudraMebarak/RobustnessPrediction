Prerequisites:

  * Familiarity with basic Git commands (e.g., `git init`, `git checkout`, `git add`, etc.)
  * Basic knowlege of programming concepts
  * GitHub account and access to a repository

Step 1: Create your own GitHub Account
If you don't allready have one, sign up for an account at https://github.com/

Step 2: Set Up Your Local Repository
1) Open your terminal window or command prompt
2) Navigate to where you want to store your project files
3) Run the following command to initialize a new Git repository:
   ```
   git init
   ```
4) Commit the initial state by running:
   ```
   git add .
   git commit -m "initial commit"
   ```

Step 3: Create a New Branch
1) Run the following command in your terminal to switch branches (if not already set):
   ```
   git checkout -b my-branch
   ```
   This creates a local copy of your project called "my-branch".

Step 4: Make Code Changes
1) Edit your project file(s) as desired
2) Add all modified files to your staging area (this adds them to the index so that Git knows what to include when committing): 
   ```
   git add <file_name>
   ```
3) Commit your code changes by running:
   ```
   git commit
   ```
   A message will be prompted.

Step 5: Push the Branch to GitHub
1) Switch back to your original branch (in this case master) by running:
   ```
   git checkout master
   ```
   If neccessary, delete any untracked files by running:
   ```
   git clean -fd
   ```
   Or remove any previously committed changes by running:
   ```
   git reset --hard origin/master
   ```
   
2) Pull down the latest updates from your remote (origin) repository by running:
   ```
   git pull
   ```
   (Note that this assumes there are no unmerged changes in the current branch.)

3) Push your updated code to the remote (origin) repository by running:
   ```
   git push origin <branch_name>
   ```
   (Replace `<branch_name>` with your actual branch name)

Step 6: Submit a Pull Request
Once your changes are pushed to your remote (origin), go to your GitHub profile and navigate to your repository settings. Click the "Pull requests" tab and click "New pull request". On the left sidebar, select the base (your forked repository) and compare it against your target (the remote repository). Enter a title and description for your pull request, then review the diff and make sure everything looks correct. Finally, submit your pull request!

Verification:

  * Check out the target (remote) repository and verify your code is present
  * Compare your local branch history (using the history viewer) with the target (remote) repository to ensure your code has been properly integrated
  * Look over the pull request comments and reviews (if any) to see if anything needs further work
  * Once the pull request is approved, merge it into the target repository (be careful not to overwrite your changes!) To verify that your code is correctly added to your project, navigate to your project directory and run `git status`. The output should show that your branch contains only your newly committed changes, and nothing else from the parent branch (master in this example).

GitHub instructions:

  * Go to the "Repository Settings" page
  * Under "Branches", select your specific branch (in this exmaple, "master") as the target
  * Select the checkbox next to your code changes that you just committed (or the entire branch)
  * Click "Submit pull request"

This concludes our step-by-step guide for creating a Git branch, making code changes, pushing the branch to GitHub, submitting a pull request, and verifying that your code is correctly added to your project using GitHub's web interface. With these steps, you'll be ready to start working collaboratively with other developers! 

Remember that it's always a good idea to keep your local and remote repositories up-to-date regularly, even if you're not actively working on a particular feature or bug fix. Regularly pulling down the latest updates from your remote can help prevent accidental merges or overwriting your progress.
