**Warning Signs Identification Guide for Beginners**

In this guide, you will learn how to identify common warning signs of a malicious website. By following these steps, you will be better equipped to protect yourself online.

**Step 1: Basic Browser Configuration (Time: 1 minute)**

1. Open your web browser (e.g., Google Chrome, Mozilla Firefox)
2. Check your browser's built-in settings (e.g., history, bookmarks)
	* Make sure you are using a private or incognito mode
	* Check for any suspicious settings (e.g., auto-fill, cookies)
3. Close the tab or window containing any suspicious links or websites
4. Verify that your browser's extension manager (e.g., uBlock Origin, AdBlock) is not active
5. Check the website's address bar and URL
	* Make sure it's not a phishing website (e.g., login credentials, email addresses)
