## Step 1: Ensure the Event Hosts Understand the Importance
The event host should understand the value of collecting and summarizing feedback to improve future events. This ensures the host is committed to creating a positive and engaging experience for attendees.

## Step 2: Identify the Feedback Channels
Define the Feedback Collection Objective
Clearly define the objective of the feedback collection process. In this case, it is to gather feedback that will help improve future events. This objective should be specific, measurable, achievable, relevant, and time-bound (SMART).

## Step 3: Identify the Collection Methods
Decide on the collection methods for feedback. Common methods include surveys, interviews, focus groups, and social media polls. Each method should be tailored to the specific event and audience.

## Step 4: Design the Feedback Collection Process
Create a step-by-step guide for collecting feedback. This includes:
- Pre-event survey or questionnaire to gather basic information
- In-event surveys or questionnaires
- Post-event surveys or questionnaires
- Follow-up interviews or focus groups
- Social media polls or online feedback forms

## Step 5: Ensure Data Quality
To ensure the quality of the feedback, establish clear guidelines for data collection, analysis, and verification. This includes:
- Defining the scope of the feedback collection
- Establishing data collection tools and methods
- Setting up a system for data analysis and verification
- Ensuring that all data is anonymized and protected

## Step 6: Verify Completion
Create a system to verify the completion of the feedback collection process. This includes:
- Setting a deadline for submission of feedback
- Creating findings. This report should include the key takeaways, recommendations, and any actions that need to be taken.

## Step 8: Verify Completion
The event host should verify that the feedback collection and summarization process is complete. This ensures that the process was successful and that the feedback was collected and analyzed accurately.

## Step 9: Store and Share the Report
The event host should store the report and make it available to authorized personnel. This ensures that the report is accessible and can be referenced as needed.

## Step 10: Evaluate the Outcome
The event host should evaluate the outcome of the feedback collection and summarization process. This involves reviewing the report to determine if any changes were made as a result of the feedback and if the event improved as a result.
