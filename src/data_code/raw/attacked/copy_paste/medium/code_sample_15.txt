This Java program defines a `StreamingMedianTracker` class that tracks and retrieves the median from an input stream of numbers in real-time. It uses two heaps: one for keeping track of smaller elements (`small`) and another for bigger elements (`big`). The median is calculated as the average of the largest element in the smaller heap and the smallest element in the larger heap. If one of them does not exist (e.g., after adding new entries), then the median is simply the only element in the non-empty heap.
