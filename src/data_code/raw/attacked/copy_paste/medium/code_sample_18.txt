This Python class `FenwickTree` supports three main operations:

1. **Point Update**: Allows adding a value at any specific index in the array.
2. **Prefix Sums**: Calculates the running total up to each index in the array.
3. **Range-Sum Queries**: Determines the total count between two given indices.

To use this class:

- Create an instance by providing its size (total number of elements).
- Use the `update()` method to increase the frequency of any element in the array.
- Employ the `sum()` method to find the cumulative count leading up to any particular position.
- Utilize the `range_sum()` function to compute the total numbers within specified ranges efficiently.
