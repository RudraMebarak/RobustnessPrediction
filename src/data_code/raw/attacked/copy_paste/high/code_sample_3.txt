def stable_counting_sort(arr):
    """
    Sorts an array of non-negative integers in ascending order using stable counting sort algorithm.
    
    :param arr: List[int] - The list of non-negative integers to be sorted.
    :return: List[int] - Sorted list of integers.
    """

    if not arr:
        return []

    max_val = max(arr)
    count_arr = [0] * (max_val + 1)

    # Count occurrences of each number
    for num in arr:
        count_arr[num] += 1

    # Reconstruct the sorted array
    sorted_arr = []
    for i, freq in enumerate(count_arr):
        sorted_arr.extend([i] * freq)

    return sorted_arr

``` `stable_counting_sort` implements a stable version of the counting sort algorithm which is capable of sorting lists of non-negative integers while preserving the original sequence of equal elements. It first determines the maximum value in the array to size up the `count_arr`. Then it keeps track of how many times each integer appears using the `count_arr` array. Finally, starting from the end of the input array, it places each element in its correct position in the output array determined by its cumulative count and then updates `count_arr` accordingly. This ensures that all elements are placed according to their original indices where they occurred within subarrays formed by repeated entries in the input array.
