This C program creates two threads that attempt to increment a shared counter concurrently. It utilizes `pthread_mutex_t` (a type of pthread mutex), which provides mutual exclusion between these operations. Thus, it prevents race conditions where one thread might read an intermediate value while another is modifying it.

The key points:
- Threads share the same memory space.
- Without synchronization, both could be reading/writing simultaneously leading to unpredictable results.
- Mutex ensures only one thread can execute at any time.
- Exiting with cleanup helps ensure all resources are freed correctly when the program ends.
