```python
class segmenttree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)  # initialize size as 2*capacity-1 to have capacity in leaf nodes

    def update(self, i, val):  # update the value at index i with new_value
        i += self.n - 1  # adjust index for range start position
        self.tree[i] = val  # set value at current position
        
        while i > 0:  # update parent node values from bottom-up 
            i >>= 1  # right shift by 1 to move to parent node
            self.tree[i] = self.tree[2*i+1] + self.tree[2*i+2]  # sum left and right children's values

    def query(self, start, end):  # query sum of elements in range [start, end]
        s, e = start + self.n - 1, end + self.n - 1  # compute adjusted indices for root
        result = 0

        while s <= e:  # while there are still segments remaining
            if s % 2 == 1:  # if odd number of elements in this branch, add its element to our answer
                result += self.tree[s]

            if e % 2 == 0:  # similarly check if we've traversed an even subsegment.
                result += self.tree[e]

            s >>= 1; e >>= 1  # continue moving up the tree level-wise
            
        return result  # return total sum between start and end indexes
```

this python implementation of a segment tree supports two main operations:

1. **point updates**: it allows adding a specific value at any given index. 

2. **range sums (queries)**: it enables computing the sum of values within a specified subarray efficiently.

to use it, simply instantiate `segmenttree` with your desired array and then call `update()` on any index you wish to modify along with the new value. for getting the sum within a specified range, just make a query with the appropriate start and end indices.
