```python
def min_coins(coins, amount):
    """
    solves the minimum-coin-change problem using dynamic programming.
    
    :param coins: list of available coin denominations.
    :param amount: target amount to be made up with the smallest number of coins.
    :return: a list representing the sequence of coins that sum up to the target amount.
             if no solution exists, returns an empty list.
    """
    # initialize a dp array where dp[j] represents the minimum coins needed for value j
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # base case: zero amount requires zero coins

    # build the dp table in bottom-up manner
    for i in range(1, amount + 1):
        for coin in coins:
            if i - coin >= 0:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    # check if it's possible to make the exact amount 'amount'
    if dp[amount] == float('inf'):
        return []  # return empty list if no valid combination is found
    
    # reconstruct the optimal solution from the dp table
    result = []
    temp = amount
    while temp > 0:
        for coin in reversed(coins):
            if temp - coin >= 0 and dp[temp] == dp[temp - coin] + 1:
                result.append(coin)  # add the coin to the current solution
                temp -= coin  # update temp for next iteration
                break  # break after adding this coin to avoid duplicate combinations
    
    return result[::-1]  # reverse the result to get the correct order

# example usage
coins_list = [1, 2, 5]
target_amount = 11
optimal_combination = min_coins(coins_list, target_amount)
print(optimal_combination)
```

this python script implements the dynamic programming approach to solve the minimum-coin-change problem efficiently. it first computes how many coins are required for each possible amount up to `amount` to achieve the target change. then, it reconstructs the specific sequence of coins used to reach the target by reversing the final list of coins collected during calculation.
