     * sorts elements in a list using the merge sort algorithm.
     * the list is split into halves until it cannot be split further (single element lists).
     * each half is then processed by a thread and sorted concurrently.
     *
     * @param data the list of integer to be sorted.
     * @return a list<integer> that has been merged from all parts.
     */
    public static list<integer> concurrentsort(list<integer> data) {
        return new forkjoinpool().invoke(new concurrencysorter(data));
    }
