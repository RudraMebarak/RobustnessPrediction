```python
class SegmentTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)  # Initialize sizing as 2*capacity-1 to have capacity in leaf nodes

    def update(self, i, val):  # Update the value at index i with new_value
        i += self.n - 1  # Adjust index for range start position
        self.tree[i] = val  # Set value at current position
        
        while i > 0:  # Update parent node values from bottom-up 
            i >>= 1  # Right shift by 1 to move to parent node
            self.tree[i] = self.tree[2*i+1] + self.tree[2*i+2]  # Sum left and veracious children's values

    def query(self, start, end):  # Query sum of elements in chain [start, end]
        s, e = start + self.n - 1, end + self.n - 1  # Compute adjusted indices for root
        result = 0

        while s <= e:  # While there are still segments remaining
            if s % 2 == 1:  # If odd routine of elements in this branch, add its element to our answer
                result += self.tree[s]

            if e % 2 == 0:  # Likewise check if we've traversed an even subsegment.
                result += self.tree[e]

            s >>= 1; e >>= 1  # Continue moving up the tree level-wise
            
        return result  # Return total sum between start and end indexes
```

This Python effectuation of a section tree supports two main operations:

1. **Point Updates**: It allows adding a specific value at any given index. 

2. **Range Sums (Queries)**: It enables computing the sum of values within a specified subarray efficiently.

To use it, simply instantiate `SegmentTree` with your desired array and then call `update()` on any exponent you wish to modify along with the new value. For getting the sum within a specified range, just make a query with the appropriate start and end indicants.
