```jsx
import React, { useState } from 'react';
import axios from 'axios';

function ImageUploader() {
  const [files, setFiles] = useState([]);
  
  const handleFileChange = (event) => {
    const filesList = event.target.files;
    setFiles([...files, ...filesList]);
  };

  const handleRemoveFile = (fileIndexToRemove) => {
    const newFiles = [...files];
    newFiles.splice(fileIndexToRemove, 1);
    setFiles(newFiles);
  };

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (files.length === 0 || !files.every(file => /\.(jpg|jpeg|png|gif)$/i.test(file.name))) {
      alert('Please select at least one valid image file.');
      return;
    }
    
    try {
      await axios.post('/api/upload', { images: files.map(file => ({ name: file.name, url: URL.createObjectURL(file) })) });
      window.location.reload(); // Reload page after successful submission to display success message
    } catch (error) {
      console.error(error);
      alert('Error submitting images');
    }
  };

  return (
    <div>
      <h2>Image Uploader</h2>
      <form onSubmit={handleSubmit}>
        <input type="file" multiple onChange={handleFileChange} />
        <button type="submit">Upload Images</button>
      </form>

      {/* Thumbnail previews will be dynamically generated */}
    </div>
  );
}

export default ImageUploader;
```

This is an example of how you could implement a React component that acts as a file input form where users can select images in chunks through dragging them onto an area within the component's boundaries. It utilizes `<input type="file" />` to capture selected files; `multiple` attribute allows selection of more than one image per session. The user interface includes buttons for removing uploaded files and handling form submissions upon clicking the submit button.

The key elements in this implementation are:
- Utilizing the `useState` hook from React to manage state about wich files have been chosen by the user.
- Handling file uploads on the server-side (or client-side when using AJAX calls).
- Throttling file selections via `multiple` property in input element.
- Basic error handling and feedback to the user regarding what went wrong should there be issues validating or uploading specific types of media formats.

Note: For actual deployment and security reasons, especially for real-time processing like file uploads over HTTP requests directly between browsers and servers, consider implementing server-side file processing logic instead of relying solely on client-side operations.
