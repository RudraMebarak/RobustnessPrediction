The algorithm Knuth-MorrisPratt computes a list of all possible patterns in text using the "simple Instances" function. The "prefixArray" contains the following values: a private static void with arguments "1,2,3,4,5". If you've tested out a pattern, it only returned 1,2,4! When you test again later, the pattern is empty, and the matching pattern doesn't even matter, if it's "ABABCBAABC."
