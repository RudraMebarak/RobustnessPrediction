2. **design**

3. **code**
   - write the html, css, and javascript code for your application. ensure it works as expected and is accessible.
   - include a readme file with installation and usage instructions.

4. **testing**
   - test your application to ensure it works as expected on different devices and browsers.

5. **documentation**
   - write a project overview and steps to reproduce the application.

6. **final touches**
   - include screenshots or a video walkthrough of the application.
   - write a project evaluation and conclusion.
