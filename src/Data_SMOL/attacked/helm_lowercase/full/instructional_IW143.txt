prerequisites:
1. basic understanding of microsoft word.
2. the ability to collaborate on a document with others.

step 1: open the shared document
start by opening the shared document you are working on. you can do this by clicking on the document's tab at the bottom of the screen or by searching for it in your file explorer. 

step 2: review the conflicting edits
look through the document for any changes that contradict what you've made or want to maintain. conflicting edits could include different fonts, formatting styles, or even different versions of the same text.

step 3: identify the author
click on the 'revisions' tab at the top of the screen. this will open a list of the different versions of the document. click on the version you want to keep, which is usually the one you initially worked on. 

step 4: use the eraser tool
click on the 'eraser tool' in the 'revisions' tab. this tool will allow you to revert changes made by another author. click on the changes you want to erase. the changes will disappear from the document.

step 5: confirm the eraser
after erasing the changes, you should check the document to make sure no conflicting edits remain. you can do this by reading through the document carefully or by comparing it to a version you trust.

step 6: save the document
finally, save the document to ensure that any changes you made are retained. click on 'save' and then choose where you want to save the document. 

verification steps:
1. check the document for any remaining conflicting edits after you've erased the changes.
2. compare the final version to a trusted version, like the original or a version you checked over.
3. ensure the formatting, text, and other elements match what you intended.

by following these steps, you should be able to resolve conflicting edits in a shared document with confidence. 

note: this guide assumes you are working on a word document. the exact steps might vary slightly depending on the version of word you are using.

## additional tips for collaborative document editing

1. **use track changes**
- this feature allows you to see all changes made by others and respond accordingly. it's particularly helpful for larger documents or when working on a timeline.

2. **set up comments**
- this lets you add notes or questions directly on the document. it's a great way to keep track of discussions and decisions.

3. **use the collaborator list**
- this shows you who's been working on the document. it's useful for identifying who might be responsible for certain sections or changes.

4. **set up a commenting chain**
- this allows you to see changes and how they relate to each other. it's helpful for understanding the thought process and reasoning behind edits.

5. **test changes**
- before committing changes, test them in a new document. this ensures you understand how changes will affect the layout or text.

6. **keep your document updated**
- regularly save your changes so you don't lose them. if you're collaborating with others, make sure you're saving regularly to avoid data loss.

---

## troubleshooting common issues in collaborative document editing

1. **unintended changes**
- this might happen when you or another author accidentally changes something you want to keep. use the eraser tool or track changes to find these unintended changes.

2. **conflicting fonts and formatting**
- this can happen when multiple people work on the same section. make sure you check over changes carefully or use the eraser tool to correct these.

3. **lost changes**
- this might happen if you're collaborating over a network or if your document gets corrupted. regularly save changes and keep a trusted version of the document.

4. **slow load times**
- this might happen when you're working on a large document with many revisions. close unnecessary programs or try to work offline if possible.

5. **display issues**
- this might happen if you're using an older version of word or if you have a slow computer. update your word version or try to work on a faster computer.

6. **difficult to read**
- this might happen if you're working on a very large document with many changes. consider breaking the document into sections or using a different editing tool.
