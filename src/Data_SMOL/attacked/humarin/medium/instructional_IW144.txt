Basic knowledge of file management on your operating system (Windows, macOS, or Linux) is required. Permission to access and manage files in a shared directory. This guide assumes that you are using a file management tool such as Windows Explorer, macOS Finder, or Linux File Manager. The steps may differ slightly depending on the software used; if you want to preserve team-wide archives for your entire project, you might need to set up an even more powerful system (such as version control system like Git, but with team access permissions), or use some type of file-sharing platform where you can share files with the team.
