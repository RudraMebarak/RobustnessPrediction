Explain the workings of the various stages of a compiler pipeline, including lexical analysis, parsing, optimization, code generation, and assembly. The lexical analysis stage breaks down the input code into a sequence of tokens, while the parsing stage uses the output from the optimization stage to improve the performance of the program. Let's take hypothetically a look at the stages of the compiler pipeline, such as this: c int main()  5; x = x + 1; return x;   1. **Lexical Analysis**: The lexical analyzer reads the input code character by character. It determines if it is a keyword, identifies it as an identifier, and then processes it as a token stream.
